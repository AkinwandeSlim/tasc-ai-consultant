# Frontend Design Constitution

## Product Philosophy

TASC AI Consultant is NOT a chatbot.

It is an Enterprise AI Consultation Platform.

Every screen should communicate:

- Professionalism
- Trust
- Intelligence
- Enterprise readiness
- Simplicity

Never resemble Discord, Slack or ChatGPT.

Instead resemble:

- Linear
- Stripe Dashboard
- Vercel
- Retool
- OpenAI

---
